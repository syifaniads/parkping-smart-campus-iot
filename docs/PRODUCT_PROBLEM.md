# Product Problem

## Problem statement

The source presentation describes campus parking areas as overcrowded during peak class hours. Students and staff can lose time searching for empty slots, adding internal traffic and increasing the burden on security staff monitoring occupancy.

## Why it matters

The presentation highlights four expected benefits:

- improve time efficiency by showing available spaces;
- improve parking management for security personnel;
- reduce vehicle congestion;
- support a smart-campus vision.

## Target users

The source lists:

- students;
- lecturers and staff;
- campus security personnel;
- campus visitors.

## Product boundary

ParkPing's core job is **occupancy visibility**, not identity tracking. That boundary is important because the source explicitly aims to avoid storing personal vehicle data.
