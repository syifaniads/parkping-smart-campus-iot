## Interview talking points

1. **Why MQTT?** Small, asynchronous sensor telemetry and decoupling between devices and consumers.
2. **Why IoT Core?** Managed MQTT/device-identity boundary aligned with certificate-based communication.
3. **What would you test first?** Sensor accuracy and noisy readings before optimizing the cloud architecture.
4. **What is the hardest production problem?** Device lifecycle: provisioning, certificate rotation, connectivity, stale data, and physical maintenance.
5. **How do you avoid overclaiming?** The retained artifact is an architecture presentation, so this repository distinguishes source-verified design decisions from unverified deployment claims.
